보고서 이메일 발송 설정

Gmail 발송은 인증한 Gmail 계정과 같은 주소를 입력하세요. 다른 발송 서비스는 인증한 도메인 주소를 사용합니다. 빈 값 저장은 발송 중지이며, 설정 저장은 시험 메일을 보내지 않습니다.

일시 중지는 다음 전송부터 적용됩니다. 재개하면 취소하지 않은 당일 대기를 처리합니다. 회차 취소는 되돌릴 수 없으며, 이미 전송 중이거나 발송된 메일은 회수하지 못합니다.

구독자를 불러오면 발송 설정과 최근 결과도 확인합니다.
