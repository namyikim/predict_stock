# 수출 통계 일일 반영

매일 **10:17 KST**에 `.github/workflows/monthly-longterm.yml`이 삼성전자와 SK하이닉스를 순서대로 갱신한다. 수동 실행과 관련 코드 변경 시에도 실행할 수 있다. GitHub 예약 실행은 지연될 수 있다.

1. 실적 예상 도구가 월간 수출과 관세청 10일·20일·월말 잠정치를 조회한다.
2. 월간 자료가 있으면 우선 사용한다. 10일보다 20일치를 우선하며, 부분월은 전년 같은 기간 증가율을 전년 동월 전체 수출에 적용한다. 월말 잠정치는 추정하지 않고 월 전체 수출액을 사용한다.
3. 실제 사용한 계열을 `exports_snapshot.json`으로 저장한다. 장기 전망도 이 스냅샷을 사용하며, 두 결과에 같은 해시를 기록한다.
4. 장기 전망에 최신 수출 증가율·가속도·국면·주가 대비 수출 지표·합성 사이클 점수와 수출 민감도 시나리오를 별도로 계산한다. 기존 월말 가격을 고정하므로 현재 주가의 예측으로 읽지 않는다. 과거 월간 검증 성적을 속보 시나리오의 성적으로 표시하지 않는다.
5. 종합 보고서의 장기 전망 요약·상세·실적 예상과 자료원 표를 교체하고 Pages 재빌드를 요청한다. 일일 예측과 채점 원장은 이 과정에서 수정하지 않는다. 실적 추정 원장은 기존 정책대로 이번 실행을 추가한다.

## 실패와 재시도

- 조회 실패 시 마지막 성공 보관본을 사용하고 그 사실을 표시한다. 다음 날 다시 조회한다.
- 실적 예상 또는 장기 전망 생성에 실패하면 종합 보고서 교체 단계는 실행하지 않는다.
- 두 결과의 스냅샷이 다르거나 기존 탭을 식별하지 못하면 화면 교체를 중단한다.
- 다른 실행이 페이지를 갱신해 충돌하면 최신 페이지를 다시 읽고 장기 탭만 교체한다.

## 범위와 검증

이 갱신은 수출 통계를 사용하는 실적 예상과 장기 전망에 적용한다. OECD·금리 등 별도 통계는 각 자료원의 실제 최신 발표치를 사용한다. 과거 검증 그래프와 고정된 주간 브리핑은 당시 기준을 유지한다. 속보 기반 주가 민감도는 별도 검증 전이며 구간을 제공하지 않는다.

`tests/test_export_refresh.py`는 기간 교체, 월간 우선, 31일 월말 표식, 누락·비정상 자료, 과거 행 보호, 탭 교체와 동시 발행 충돌을 검증한다.
