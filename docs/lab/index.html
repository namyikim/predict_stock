실제 거래는 하지 않았습니다. 개장 전 예측으로 계산한 가상 계좌입니다.
계산 기준과 제외 조건 장 시작 후 예측은 시가에 거래할 수 없어 제외하며, 대체 진입 가격이 확보되기 전에는 성과를 내지 않습니다.
예측 기반 전략과 매일 장중 보유는 시가 매수·종가 청산, 매수 후 보유는 첫날 시가 매수·마지막 날 종가 청산입니다. 정수 주식 수와 잔여 현금, 체결 금액별 수수료·매도세·슬리피지를 반영합니다.
관측된 날짜만 평가하므로 최대 낙폭은 관측일 종가 기준입니다. 배당·기업행사·실제 호가·미체결은 반영하지 않습니다. 비용은 가정값이며 실제 계좌 요율을 입력해야 합니다. 비용을 0으로 낮추는 실험은 별도 민감도 모드에서만 가능합니다. 실제 시가·종가 체결을 보장하지 않으며, 과거 예측에 지금 선택한 규칙을 적용한 결과는 자동 모의운용 실적과 다릅니다.
