# 삼성전자·SK하이닉스 AI 일일예측 설계

## 목적과 범위

매 거래일 아침 AI가 삼성전자와 SK하이닉스의 당일 시초가, 종가 방향, 종가를 직접 판단하고, 장 마감 뒤 실제값과 비교해 장기간의 성과를 투명하게 기록한다.

이 기능은 다음 시스템과 완전히 분리한다.

- 기존 주가 방향·가격 예측 모델
- 거시경제 페이지와 거시경제 판정
- 기존 `forecast_history` 원장과 가상 매매 점수

AI 판단에 기존 모델의 예측값이나 점수를 입력하지 않는다. 공개 시장자료와 당일 판단 근거만 사용하며 투자 자문으로 표현하지 않는다.

## 운영 방식

현재 주간 반도체 보고서와 같은 예약 작업 방식으로 운영한다. 저장소 안에서 OpenAI API를 호출하지 않으며 별도의 `OPENAI_API_KEY`를 요구하지 않는다.

### 오전 예측 작업

- 평일 08:00 KST 실행한다.
- 한국거래소 거래일이 아니면 아무 예측도 만들지 않는다.
- 최신 가격, 전일 미국 시장, 환율, 반도체 업황 및 공개 뉴스를 확인한다.
- 삼성전자와 SK하이닉스 각각에 대해 시초가, 종가 방향, 종가 및 짧은 판단 근거를 작성한다.
- 종가 방향은 **전일 종가 대비** 상승·보합·하락으로 정의한다.
- 날짜별 기록을 GitHub `main`에 반영한다.
- 09:00 KST 이후에는 예측 필드를 수정하지 않는다.

### 오후 채점 작업

- 평일 16:10 KST 실행한다.
- 확정된 실제 시초가와 종가를 가져온다.
- 오전에 저장된 예측이 있을 때만 채점한다.
- 예측 필드는 보존하고 실제값과 채점 필드만 추가한다.
- 휴장, 거래정지, 데이터 미확정 또는 데이터 수집 실패 시 값을 추측하지 않고 상태와 실패 사유를 기록한다.

## 데이터 구조

기록은 기존 예측 원장과 분리된 `ai_daily_forecast/` 아래에 둔다.

- `ai_daily_forecast/YYYY-MM-DD.json`: 해당 날짜의 두 종목 예측과 사후 실제값
- `ai_daily_forecast/index.json`: 화면이 읽는 날짜별 요약 및 누적 통계

날짜별 JSON에는 다음 항목을 둔다.

- 스키마 버전, 대상 거래일, 생성 시각과 채점 시각
- 종목 코드와 종목명
- 전일 종가
- 예측 시초가
- 예측 종가 방향
- 예측 종가
- 판단 근거와 확인한 주요 출처 링크
- 실제 시초가와 실제 종가
- 방향 적중 여부
- 시초가 절대오차율과 종가 절대오차율
- 상태: `predicted`, `scored`, `market_closed`, `data_pending`, `failed`

동일 날짜 파일을 다시 실행해도 예측은 덮어쓰지 않는다. 오후 작업은 허용된 실제값·채점 필드만 갱신한다.

## 채점과 누적 성과

임의의 가중치를 섞은 단일 100점 점수는 사용하지 않는다. 서로 의미가 다른 성과를 다음과 같이 분리해 누적 표시한다.

- 종가 방향 적중률: 맞힌 거래일 수 ÷ 채점된 거래일 수
- 시초가 평균 절대 백분율 오차(MAPE)
- 종가 평균 절대 백분율 오차(MAPE)
- 채점된 거래일 수

각 종목별 성과와 두 종목 전체 성과를 함께 제공한다. 표본이 적을 때는 반드시 건수를 함께 보여 주며, 데이터가 없는 날은 분모에서 제외한다.

## 화면

`docs/lab/index.html`에 세 번째 탭 **AI 일일예측**을 추가한다. 이 실험실은 현재처럼 `docs/admin/index.html`을 통해 접근하며 검색엔진에는 노출하지 않는다.

탭 구성은 다음과 같다.

1. 최신 예측: 두 종목의 예측 시초가, 종가 방향, 예측 종가, 판단 근거
2. 실제 결과: 실제 시초가·종가, 방향 적중 여부, 가격 오차
3. 누적 성과: 종목별 방향 적중률과 시초가·종가 MAPE, 표본 수
4. 전체 이력: 날짜별 예측과 실제값을 비교하는 표

화면에는 기존 알고리즘의 결과가 아니라 AI가 해당 시점에 직접 남긴 판단이라는 점, 실험 기록이며 투자 자문이 아니라는 점을 명시한다. 원장을 불러오지 못할 때는 빈 값을 성공처럼 표시하지 않고 오류 안내를 보여 준다.

## 실패 처리와 감사 가능성

- 08:00 작업이 실패하면 그날 예측이 없음을 명확히 남기고 장 시작 뒤 소급 예측하지 않는다.
- 16:10에 실제값이 확정되지 않으면 `data_pending`으로 두고 다음 실행에서 재시도한다.
- 출처 링크와 생성 시각을 보관해 당시 알 수 있었던 정보와 사후 정보를 구분한다.
- 예측 생성 커밋과 채점 커밋을 분리해 사후 수정 여부를 Git 기록으로 확인할 수 있게 한다.
- 비밀키, 인증 토큰, 뉴스 전문은 저장하지 않는다.

## 검증

- JSON 스키마와 필수 필드 검증
- 09:00 이후 예측 필드 불변성 검증
- 전일 종가 대비 방향 채점 단위 테스트
- 시초가·종가 MAPE와 누적 집계 단위 테스트
- 휴장일·거래정지·데이터 미확정 처리 테스트
- `docs/lab/index.html`의 탭, 빈 상태, 오류 상태, 최신 예측 및 누적 표 렌더링 테스트
- 기존 실험실 두 탭과 공개 보고서에 영향을 주지 않는 회귀 테스트

## 완료 조건

- 두 예약 작업이 정해진 시간에 실행된다.
- 예측이 장 시작 전에 Git에 기록되고 이후 변경되지 않는다.
- 장 마감 뒤 실제값과 채점이 같은 날짜 기록에 추가된다.
- `admin → lab → AI 일일예측`에서 최신 결과와 누적 성과를 볼 수 있다.
- 거시경제 및 기존 주가예측 데이터와 코드 경로가 섞이지 않는다.
- 관련 테스트와 전체 회귀 테스트가 통과한다.
