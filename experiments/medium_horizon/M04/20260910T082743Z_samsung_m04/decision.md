# M04 — 5·20일 직접 방향 확률 모델 (2026-09-10)

실행: `20260910T082743Z_samsung_m04`, `20260910T082806Z_sk_hynix_m04` (full, 고정 입력 캐시).
라벨: h일 누적 수익률(d-1 종가 대비 d+h-1 원본 종가)을 밴드 = 20일 변동성 × sqrt(h) × 0.3 으로 하락/보합/상승 3클래스(초기 계약, 평가 결과로
조정하지 않았다). 모델: StandardScaler + 다항 Logistic, C ∈ {0.003, 0.01, 0.03}, class_weight=None. 폴드마다 내부 3구간 합산 log loss 로 C 를
고르고 같은 예측으로 온도 ∈ {1, 0.75, 1.5, 2} 를 고른다. 기준: 학습 구간 클래스 사전확률. 기존 `fit_direction_model`(1일 계약)은 부르지 않고
중기 전용 경로(`fit_direction_probabilities`, M01 폴드 계약의 날짜 purge)를 썼다. 평가 = 개발 9폴드 공통 행(1,081~1,086).

  말하는 셈이다. 그래도 외부 log loss 는 사전확률보다 나빠지는 쪽(4조합 모두 delta > 0, 유의하지는 않음)이다. 20일 지평은 폴드별 편차가 크다

  항상 다수 클래스를 내므로 balanced accuracy 가 정의상 1/3 이고, 확률 품질(log loss·Brier)은 개선되지 않았다. 방향 확률 모델로서 채택
  근거가 되지 않는다. 가격 회귀의 부호 적중률과는 섞지 않았다(별도 표).
- 클래스 비율(개발 구간): 하락 32~41% / 보합 23~26% / 상승 35~43%. 확률 합=1·유한값·없는 클래스 처리는 실행 중 검사와 테스트로 확인.
