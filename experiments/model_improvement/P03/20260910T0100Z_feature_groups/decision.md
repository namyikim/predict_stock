# P03 기존 특징군의 추가 가치

**결론: 어떤 특징군도 채택하지 않는다. 현행 대표 모델 `No macro ensemble`(시세만)을 유지한다.**

기준선은 `experiments/model_improvement/P00/20260910T0100Z_baseline_full`이다. 노트북이 같은
폴드·같은 날짜로 이미 계산한 쌍체 비교를 읽었다. 다시 학습하지 않았다.
평가일 samsung 1,362 / sk_hynix 1,357, **결측으로 제외된 날짜 0**.

## 읽는 법

- **개선된 특징군은 하나도 없다.** 방향 정확도는 전부 동률이고, 확률 품질은 넷 중 셋이
  적어도 한 종목에서 유의하게 나빠졌다.
- **월별 지표는 두 종목 모두 유의하게 열위다.** 현행 `HEADLINE_MODEL = "No macro ensemble"`
  선택을 뒷받침한다. 월+2 지연 정렬한 최신 수정치라 과거 시점 정보로서 약한 것과도 맞는다.
- 정확도 동률 + 확률 열위는 **상충이 아니다.** 정확도에서 얻은 것이 없고 확률만 나빠진 것이다.
- 수급과 거시 가격은 종목별로 판정이 갈린다. 계획 규칙대로 각각 판단하며 한 종목 결과를
  다른 종목에 적용하지 않는다.

## 채택

없음. **P04의 고정 특징 목록은 `No macro ensemble`의 입력**, 즉 `macro_`·`nsi_`·`flow_`를
뺀 시세 특징군이다(51개 + 거시 가격 8개 = 59개). 거시 가격은 samsung에서 경계적으로 열위지만
`No macro ensemble` 정의에 포함돼 있어 대표 모델을 바꾸지 않는 한 그대로 둔다. 분리 측정이
필요하면 P15의 사전 예측 비교로 넘긴다.

## 새 변수군

기존 입력에 명확한 공백이 있어야 후속 작업으로 기록한다. 현재 측정에서는 이미 넣은 넷이 전부
효과가 없으므로, 새 변수군 수집을 P04보다 앞세울 근거가 없다. 계획의 P09(갭·장중 분리)와
P10(공동 학습)이 더 유망하다.
