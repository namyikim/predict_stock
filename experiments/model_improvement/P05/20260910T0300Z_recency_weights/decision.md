# P05 최근 표본 가중 학습

**결론: 채택 없음. 무가중을 유지한다.** 반감기가 짧을수록 확률 품질이 나빠지며, 가장 긴
504거래일도 무가중과 동률일 뿐 낫지 않다.

기준선 `experiments/model_improvement/P00/20260910T0100Z_baseline_full`, 5년 창(P04 결론),
대표 모델 입력(시세만, P03 결론), 같은 외부 폴드 12개.
가중치 `w = 2^(-age/half_life)`, 폴드 마지막 학습 관측이 age 0, 평균 1 정규화.
`class_weight="balanced"`가 선택되면 둘이 곱해진다. 평가 지표는 날짜별 동일 가중이다.

## 내부 선택

두 종목 모두 **504**를 골랐다(내부 log loss samsung 1.0045 vs 무가중 1.0089, sk_hynix 0.9869
vs 0.9872). 외부에서 504는 무가중과 동률이므로 이번에는 내부 선택이 외부 결과와 어긋나지
않았다 — 다만 그 선택이 실제 개선을 주지도 않는다.

## 읽는 법

P04(짧은 창일수록 나쁨)와 같은 방향이다. **이 신호는 약해서 자료를 줄이거나 최근에 몰아주면
손해다.** 최근 국면 적응보다 표본 수가 중요하다. DoubleAdapt류 순차 적응(P12)을 이 결과 위에서
정당화하기는 어렵다 — 단순 가중이 이미 손해인데 더 공격적인 적응이 나을 근거가 없다.
