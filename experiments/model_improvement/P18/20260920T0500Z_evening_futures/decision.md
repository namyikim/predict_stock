# P18 전날 저녁(20:00 KST) 예측에 저녁에 거래되는 자산을 더할 수 있는가

**결론: 미채택. 저녁 예측은 나스닥·S&P 야간 선물과 유럽 지수 시간봉을 더해도 확률 품질이 나아지지 않는다(네 칸 전부 동률).**
얻은 것은 **갭 AUC 가 0.47 → 0.49(samsung) · 0.45 → 0.50(sk_hynix)** 로 조금 오른 것뿐이고, 그것도 아침 07:00 모델의
0.81 / 0.82 에는 비교가 되지 않는다. 22:00 KST(미국 개장 직전)까지 기다리면 sk_hynix 의 방향 정확도가 유의하게
오르지만(balanced_accuracy +0.053 [+0.015, +0.091]) log_loss 는 여전히 동률이고 samsung 은 그마저 없다.

**저녁 질문은 아침 질문보다 본질적으로 어렵다.** 이 모델의 예측력은 밤사이 갭에 있고(P09) 그 갭은 미국 정규장이 만든다.
20:00 KST 에는 그 정보가 **존재하지 않는다.** 저녁 기준선 `t_evening` 의 갭 AUC 0.47 / 0.45 는 사전확률과 같은 수준이며,
즉 저녁 실행의 `Candidate evening forecast` 는 **거의 사전확률을 내고 있다.** 선물·유럽 지수는 그 빈자리의 아주 작은 부분만
채운다 — 두 종목 모두 log_loss 로는 t0700 에 +0.06 / +0.10 만큼 뒤진 채 그대로다.

계획: [guides/model-improvement-plan.md](../../../../guides/model-improvement-plan.md) P18(계획 밖 등록 2026-09-20).
직접 선행: [P16 시가 확정 후 재예측](../../P16/20260920T0000Z_post_open_reforecast/decision.md)(정보 마감 시각을 뒤로 옮긴
실험 — 이번에는 앞으로 옮긴다), [P09 갭·세션 분해](../../P09/20260910T0700Z_gap_session_legs/decision.md).

## 채택 규칙 (결과를 보기 전에 정한 것)

1. **(t_evening + F) − t_evening** 의 log_loss 95% 월 블록 CI **상한이 0 미만** — 두 종목 모두, 또는 한 종목 명확한 우위 +
   다른 종목 동률.
2. 이득이 있어도 **t0700 까지 남은 거리**를 같은 표에 적는다. 저녁 숫자를 아침 숫자와 나란히 놓고 "모델이 좋아졌다"고
   읽지 않는다.
3. 모델 없는 `nq_rule`(선물 부호 규칙)만으로 이득이 설명되면 그렇게 적는다.
4. 평가일은 시간봉 범위와 겹치고 **학습 구간에 선물 특징이 있는 행이 100 이상인 폴드**의 시험일이며, **모든 후보가 같은
   날짜**에서 채점된다.

## 설정

- 기준선·폴드: P00 과 같은 계약(`No macro ensemble` 시세만, 5년 창, 6개월 12폴드, 밴드 = 과거 20일 변동성 × 0.3, SEED 42).
  노트북은 P16 과 같은 **고정 스냅샷**(samsung `3d1a03863c448ec5d1aa` / sk_hynix `fa4dfc966108ea6024bb`, 봉 2026-09-16 까지)으로
  다시 돌렸다. 시세만 입력 61 / 58열.
- **`t_evening` — 저녁 실행이 보는 것의 재구성.** 저녁 실행(노트북 셀 1, `EVENING_WINDOW_KST=(17,23)`)은 별도 모델이 아니라
  아침 모델을 그 시각의 일봉으로 돌린 것이다. 그래서 행 d 를 다음 규칙으로 만든다(`evening_feature_frame`).

  | 열의 세션(노트북 셀 11 `ASSET_SESSION`) | 접두어 | 행 d 가 쓰는 값 | 이유 |
  | --- | --- | --- | --- |
  | korea | `sam_`·`kospi_`·`peer_` | 아침 행 d | d−1 한국 종가는 d−1 17:00 에 이미 안다 |
  | calendar | `cal_` | 아침 행 d | 예측일 자체의 속성 |
  | us | `sox_`·`nasdaq_`·`sp500_`·`micron_`·`nvidia_`·`tsmc_adr_`·`korea_etf_`·`us10y_`·`vxn_` | 아침 행 **d−1** | d−1 20:00 KST 에 마지막으로 마감된 미국 세션 = d−2 미국 날짜 = 아침 행 d−1 이 본 것 |
  | cont | `usdkrw_`·`dxy_`·`vix_`·`wti_`·`usdjpy_`·`krwjpy_` | 아침 행 **d−1** | 마감 판정 17:05 ET 이라 같은 사정 |
  | london | `target_gdr_`(samsung 만) | 아침 행 **d−1** | 런던 마감 01:30 KST |
  | cross | `gdr_overnight_signal` | gdr(행 d−1) − sam(행 d) | 두 성분을 각각의 시점에서 |

  분류할 수 없는 열은 예외로 막았다(새 열이 조용히 '한국' 취급되면 미래를 본다). `feat` 에서 다시 만든 아침 행렬이 노트북
  `market_X` 와 **최대 차이 0.0** 임을 실행마다 확인한다.
- **후보 `t_evening_f2000`** — 같은 입력 + 시간봉 특징 6열 + 가용 플래그 1열(61→68 / 58→65열). 마감은 **전 한국 세션 날짜의
  20:00 KST**, 그 시각까지 **끝난** 시간봉만 쓴다(마감에 걸친 봉 제외).
  - `nq_ret`·`es_ret`: 직전 미국 정규 세션 마감 봉(17:00 ET 전 마지막 봉 = 16:00 ET 봉)의 종가 → 마감 전 마지막 봉 종가.
    정규 마감 뒤 18:00 ET 부터의 야간 봉은 기준이 아니다. `nq_sign` = 부호, `nq_cum5` = 5 정규 세션 전 마감 대비.
  - `dax_ret`·`stoxx_ret`: 그 날짜 유럽 세션 첫 봉 시가 → 마감 전 마지막 봉 종가(20:00 KST = 13:00 CEST / 12:00 CET).
    유럽 휴장(선물은 있는데 유럽 봉이 없는 날)은 0 으로 두고 셌다 — 552 가용일 중 **16일**.
  - 자료: yfinance `interval=1h, period=730d`. NQ=F·ES=F 는 2024-04-28 부터, ^GDAXI 2023-11-02, ^STOXX50E 2023-10-18 부터
    (`runs/model_improvement/P18/cache/`, manifest `hourly_cache_hash`). 마지막 봉 2026-09-18.
  - 시간봉이 없는 학습 행은 6열 0 + 플래그 0("정보 없음"). 시험 행은 두 마감 모두 가용한 날짜만.
- **민감도 `t_evening_f2200`** — 같은 6열을 **22:00 KST**(미국 개장 22:30 직전) 마감으로. "마지막 순간까지 기다리면 얼마나
  더 얻나"를 본다. 운영 후보가 아니다(저녁 실행 창은 17~23시지만 22:00 예측은 이미 '저녁 예측'이라 부르기 어렵다).
- 참조 행(후보 아님): **`t0700`** 아침 대표 모델(상한 — P16 과 같은 기계, 같은 날짜에서 재학습), **`nq_rule`** 모델 없는
  규칙(NQ 20:00 수익률 > 종목 밴드 → 상승 / < −밴드 → 하락 / 나머지 보합. 확률은 학습 구간 버킷별 조건부 분포,
  `gap_rule_probabilities` 재사용. 규칙은 NQ 수익률을 종목 밴드에 그대로 대므로 대개 상승·하락을 말한다).
- **평가일: 두 종목 모두 394일, 2025-01-02 ~ 2026-09-16, 폴드 8·9·10·11**(시험 116·106·119·53). 폴드 0~5 는 시간봉 범위
  밖, 폴드 6·7 은 학습 구간의 선물 가용 행이 0·36 으로 100 미만이라 제외. 사용한 폴드의 학습 구간 선물 가용 행은
  158·274·380·499 — **후보는 선물 열을 많아야 500행에서 배웠다.** 이것이 시간봉 자료의 한계이고 아래 '읽는 법' 3 이다.
- 모델·결합·내부 선택은 대표 모델과 같다(`_ensemble_probabilities` = Logistic + LightGBM 확률 평균). 학습 시간 4폴드 합
  9~10초/후보.

5년) argmax 가 뒤집힌다. 입력 재구성 자체는 위 표의 세션 규칙과 `market_X` 재현 0.0 으로 고정했다. 정확한 라이브 확률
재현은 라이브 학습 창으로 다시 학습해야 하며 이 실험의 물음(선물이 더하는 몫)과 무관해 하지 않았다.

## 읽는 법 — 오해하기 쉬운 지점

1. **저녁 예측이 나쁜 것은 모델 탓이 아니다.** 20:00 KST 에는 답의 대부분을 만드는 정보(미국 정규장)가 아직 없다.
   P16 이 정보를 뒤로 옮겨 +0.10 을 얻었듯, 여기는 정보를 앞으로 옮겨 −0.06 / −0.10 을 잃는다. 같은 축의 반대 방향이다.
2. **갭 AUC +0.013 / +0.047 은 실재하지만 쓸 수 없는 크기다.** 확률로 바뀌지 않았고(log_loss 동률) sk_hynix 의 방향
   정확도 이득은 22:00 마감에서만 유의하다. 22:00 은 저녁 실행 창(17~23시)의 끝이고 미국 개장 30분 전이라 '저녁 예측'의
   의미가 희미하다.
3. **후보가 불리했다고 볼 여지가 하나 있다.** 시간봉이 2024-05 부터라 후보는 선물 열을 158~499행에서만 배웠고 그 앞 학습 행은
   전부 0 이었다. 자료가 5년 쌓이면 다를 수 있다 — 그러나 정보의 상한(갭 AUC 0.5 근처)이 낮아 확률 품질이 바뀔 여지도 작다.
   이것은 재실험의 근거이지 채택의 근거가 아니다.
4. **계획 4절대로 종목별로 판단했다.** sk_hynix 만 22:00 에서 방향 정확도가 유의하지만 log_loss 는 동률이라 '상충'이 아니라
   '확률 품질 동률'이며, 채택 규칙 1(log_loss)을 통과하지 못한다.
5. **아침 07:00 예측은 이 실험과 무관하게 그대로다.** t0700 은 참조 행일 뿐 어떤 후보도 아침 모델의 입력을 바꾸지 않는다.

## 채택

**미채택.** 채택 규칙 1(log_loss CI 상한 < 0)을 두 종목 어느 마감에서도 충족하지 못했다. 코드·노트북·보고서·원장은 바꾸지
않았다(`forecast_utils.py`·노트북·`forecast_history/`·`docs/` 무변경).

### 운영에 반영했다면 필요했을 것 (하지 않음)

- 저녁 실행이 yfinance **시간봉 4종을 실행 시각에 받아** 20:00 마감으로 잘라야 한다. yfinance 시간봉은 730일 제한·간헐적
  빈 응답·봉 라벨(시작 시각) 규칙이 문서화돼 있지 않아 일봉보다 신뢰도가 낮다. 실패하면 6열이 비고 플래그 0 으로 떨어져
  '정보 없음' 모델로 돌아가야 한다(이 실험의 학습 규칙과 같다).
- 저녁 실행 시각(GitHub cron 18:22·21:22 KST)이 곧 마감 시각이므로 **실제 실행 시각을 마감으로 원장에 적어야** 한다.
  21:22 회차는 20:00 이 아니라 21:00 마감 봉을 보게 된다.
- 위 두 가지를 감수할 만한 이득이 없다.

## 다음

- **저녁 예측을 개선하려면 정보가 필요하지 모델이 아니다.** 20:00 KST 에 존재하는 정보는 이 실험이 다 넣었다(선물·유럽).
  남은 것은 22:00~06:00 사이의 미국 정규장이고 그것을 기다리는 것이 곧 아침 실행이다.

  사전확률 수준임을 394일에서 확인했다 — 원장의 5일 표본이 노이즈였다는 뜻이다.
- 시간봉 자료가 3년 이상 쌓인 뒤(2027-05 이후) 같은 러너로 재실행할 수 있다(`--task P18 --resume`, 캐시를 지우면 새 해시).
- P15(`Candidate expanding` 관찰)·P17(as-of 결합 정리)은 그대로다.
