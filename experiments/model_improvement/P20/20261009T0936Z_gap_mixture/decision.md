# P20 — 07:00 종가 방향 = 예측한 갭 분포 × 시가 반영 모델 (2026-10-09, 채택 없음)

**가설.** P09에서 갭 타깃의 예측력(log loss −0.18~−0.24)이 종가→종가(−0.05~−0.07)보다 컸고, P16의 t0900(시가 관측)은
t0700보다 −0.10 나았다. 07:00 정보로 갭 분포를 예측해 t0900 모델을 그 위에서 평균하면 07:00 종가 방향이 나아질 수 있다.

**후보(미리 하나로 고정).** `gap_mixture`: 갭 중심 = Ridge(alpha 1e4, 07:00 시세 특징), 퍼짐 = 학습 구간 뒤 20%에서 잰
표준화 잔차(직전 60세션 갭 표준편차로 나눔)의 41개 등확률 분위. t0900(Logistic·LightGBM 평균)을 그 점들 위에서 평균.
시험 행의 실현 갭은 쓰지 않는다. 비교 기준은 같은 날짜의 t0700(현행 대표 모델과 같은 방식).

**실행.** `python tools/run_model_improvement.py --task P20 --target {samsung,sk_hynix} --mode quick` (마지막 3폴드, 294일).
Windows 로컬, Python 3.14, requirements.txt 버전. full 12폴드는 돌리지 않았다 — quick 에서 두 종목 모두 유의하게 열위라

**왜 졌나(사실).** 07:00 특징으로 예측한 갭 중심의 MAE가 '갭 0'보다 약 10%만 작다(samsung 폴드별 0.0101/0.0262/0.0265 대
0.0111/0.0292/0.0293). 갭의 부호는 잘 맞혀도(P09 AUC 0.8대) 크기는 흐려서, t0900을 넓은 갭 분포 위에서 평균하면 확률이
사전확률 쪽으로 무뎌진다. t0700은 같은 정보에서 방향 확률을 직접 배우므로 이 손실이 없다.

**결론.** 채택 없음. 결과를 보고 분위 수·규제·잔차 창을 바꿔 다시 돌리지 않는다(결과를 보고 고르는 것이 된다).
갭에서 더 얻으려면 정보 시점을 09:00 뒤로 옮기는 수밖에 없고, 그것은 이미 `Post-open` 행(P16)이 한다.
