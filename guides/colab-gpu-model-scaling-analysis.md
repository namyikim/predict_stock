# Colab GPU와 대형 모델의 주가 예측 활용 검토

작성일: 2026-09-10

## 결론

Colab GPU를 활용한 학습은 실험 가치가 있다. 그러나 현재 프로젝트에서 모델 크기만 키운다고 예측 성능이 좋아질 가능성이 높다고 보기는 어렵다. 우선순위는 학습 데이터의 확장과 미래 구간 검증이다.

첫 GPU 실험으로는 **여러 종목으로 공동 학습하는 작은 모델**을 권한다. 기존 Logistic·LightGBM 기준선 대비 개선이 확인되면 모델 크기를 단계적으로 늘린다. 이 문서는 검토 의견이며, 새 모델의 구현이나 학습 결과를 의미하지 않는다.

## 현재 구성과 제약

- `samsung_direction_model_colab.ipynb`는 Logistic·LightGBM 확률을 결합하며, 기본 학습 창은 최근 5년이다.
- 기본 대표 모델은 시세 특징을 사용하는 `No macro ensemble`이고, Transformer는 기본 비활성화되어 있다.
- 일봉 5년은 종목당 약 1,200개 안팎의 관측치다. 실제 학습 행 수는 거래일, 결측치, 특징 생성과 타깃 처리에 따라 달라진다.
- 이 규모에서 큰 신경망을 처음부터 학습하면 과거의 잡음까지 학습하는 과적합 위험이 있다. GPU는 계산을 빠르게 하지만 새로운 예측 정보를 만들어 주지는 않는다.

일반적인 중소 규모 표 데이터에서는 트리 모델이 신경망보다 강한 경우가 많다는 연구가 있다. 다만 일반 표 데이터의 결과가 이 프로젝트의 주가 예측에서도 항상 성립한다는 뜻은 아니다.

참고: [Why do tree-based models still outperform deep learning on tabular data?](https://arxiv.org/abs/2207.08815)

## 저장소의 기존 실험 근거

[모델 성능 개선 계획](model-improvement-plan.md)에 보존된 2026-09-06 Transformer 실험 기록은 다음과 같다. 이번 검토에서 다시 학습하거나 재검증한 수치는 아니다.

| 종목 | Transformer 추가 후 log loss 차이 | 95% 신뢰구간 | 저장된 판정 |
| --- | ---: | --- | --- |
| 삼성전자 | +0.009129 | [0.004410, 0.014125] | 편입 반대 |
| SK하이닉스 | +0.001705 | [-0.002672, 0.006348] | 동률 |

차이는 후보에서 기준선을 뺀 값이며, log loss는 작을수록 좋다. 이 기록에서는 삼성전자의 확률 예측 성능이 나빠졌고, SK하이닉스에서는 뚜렷한 개선이 확인되지 않았다. 모든 신경망이나 더 큰 모델이 실패한다는 증거는 아니지만, 복잡도를 높이는 것만으로는 충분하지 않다는 근거다.

## GPU 활용 후보 비교

| 방법 | 판단 | 주요 조건 |
| --- | --- | --- |
| 현재 두 종목 일봉으로 Transformer만 대형화 | 우선순위 낮음 | 데이터 대비 모델이 커지는 과적합 위험 확인 |
| 관련 종목 수십~수백 개를 모아 공동 학습 | 실험 가치 있음 | 종목 간 공통 패턴과 종목별 차이를 학습하고 날짜 단위로 평가 분리 |
| 사전학습된 시계열 모델을 소규모 미세조정 | 처음부터 대형 모델을 학습하는 것보다 현실적인 후보 | 사전학습 데이터와 평가 기간의 중복 가능성, 입력 적합성 확인 |
| 뉴스·공시에서 정보를 추출해 기존 모델에 추가 | 가격 외 정보를 보탤 가능성 | 실제 공개 시각을 지키고 기존 특징 대비 추가 기여도 검증 |

위 판단은 실험 우선순위에 대한 제안이며 성능 개선을 보장하지 않는다. 종목을 늘려도 같은 날의 시장 영향을 함께 받으므로 데이터 행 수만큼 독립적인 정보가 증가하지는 않는다.

## 권장 실험 순서와 평가 기준

1. 현재 Logistic·LightGBM 기준선과 평가 날짜, 타깃, 정보 마감 시각을 고정한다.
2. 여러 관련 종목의 데이터를 구성하고 작은 공동 학습 모델을 Colab GPU에서 실험한다.
3. 모든 종목을 같은 날짜 기준으로 학습·검증·평가 구간에 나눈다. 정규화, 모델 선택과 확률 보정도 평가 시점보다 과거인 자료에서만 수행한다.
4. 보지 않은 미래 구간에서 방향 정확도, balanced accuracy, log loss와 Brier score를 비교한다. 여러 기간에서 개선이 유지되는지 확인한다.
5. 종가 대비 다음 종가 예측을 야간 갭과 장중 방향으로 분리해 평가한다. 거래 성과를 비교할 경우 진입 가능 시각과 거래비용도 반영한다.
6. 작은 모델의 추가 효과가 확인된 경우에만 크기를 단계적으로 늘린다. 최종 평가 결과를 보고 반복적으로 설정을 조정하지 않도록 별도 최종 평가 구간을 보존한다.

현재 [README](../README.md)는 관측된 방향 예측력의 상당 부분이 야간 갭에 집중되고 장중 성능은 대체로 무작위에 가까웠다고 설명한다. 따라서 종가 방향 정확도뿐 아니라 장중 방향도 개선되는지 확인해야 GPU 실험의 실질적 가치를 판단할 수 있다.

학습에 GPU를 사용하더라도 일일 예측에 필요한 자원은 별도로 측정한다. 후보 모델의 크기와 연산에 따라 CPU 추론이 가능할 수 있으므로, 채택 전 현재 자동 실행 환경에서의 실행 시간과 메모리 사용량을 확인한다.
