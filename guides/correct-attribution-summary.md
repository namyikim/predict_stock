# 맞힌 예측의 누적 기여도 요약

위치: Admin → 실험실 → 무엇이 예측을 밀었나 → 맞힌 예측 누적 요약(기본 보기).

`forecast_history/<종목>/attribution.csv`와 `forecast_log.csv` 전체를 화면 로딩 시 함께 읽는다. 기존 원장이나 채점 결과를 변경하지 않는다.

- 모델·예측일별 최초 사전 방향 예측을 선택한다. 후속 재실행의 정답으로 대체하지 않는다.
- 실행 ID·모델·대상 날짜가 모두 일치하는 기여도만 연결한다.
- 채점 완료 및 방향 적중=1인 기록만 순위를 계산한다. 사후 실행·미채점·누락·비정상 값은 제외한다.
- 동일 실행·동일 특징의 중복 행은 한 번만 센다.
- 예측마다 저장된 요소들의 절대 기여도 합을 100%로 정규화한 뒤, 적중 예측별 동일 가중치로 평균한다. 원래 기여도 단위가 다른 실행을 단순 합산하지 않는다.
- 모델별 순위, 평균 기여 비중, 최대 기여 횟수(공동 1위 포함), 기록 등장 횟수, 표본 수·기간을 표시한다.
- 저장된 상위 요소만의 비중이며 반대 방향 기여도 포함한다. 적중 원인·요소별 적중률·전체 모델 중요도는 아니다. 기록이 없는 날은 과거 기여도를 추정해 채우지 않는다.

검증: `python -m unittest discover -s tests -p 'test_correct_attribution.py' -v`, `python -m unittest discover -s tests -p 'test_lab_page.py' -v`.
