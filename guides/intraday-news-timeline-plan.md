## 사용자가 보게 될 형태

1. 차트 위에는 날짜, 시가·종가, 장중 고가·저가를 짧게 표시한다.
2. 세로 시간축을 따라 가격선이 좌우로 움직인다.
3. 급등 전환점은 초록색, 급락 전환점은 빨간색, 거래량만 크게 늘어난 전환점은 파란색으로 표시한다.
4. 전환점 전후 뉴스는 같은 시간대 오른쪽 설명 칸에 최대 1~2건만 노출한다.
5. 같은 시간대 뉴스가 많으면 `외 N건`으로 접고, 차트 아래 기존 뉴스 목록에서 모두 확인하게 한다.
6. 정확한 시각이 없는 DART 공시는 차트에 임의로 배치하지 않고 차트 아래 별도 목록에 둔다.
7. 밤사이 뉴스는 09:00 위의 **「개장 전」** 영역에 표시하고 장중 뉴스와 구분한다.

## 데이터 구조 변경

회고 JSON에 다음 필드를 추가한다.

```json
{
  "intraday_path": [
    {"time": "2026-09-30T09:00:00+09:00", "price": 81200, "volume": 123456}
  ],
  "timeline_items": [
    {
      "time": "2026-09-30T10:35:00+09:00",
      "kind": "turn_up",
      "price": 82100,
      "ret": 0.008,
      "z": 3.4,
      "volume_ratio": 2.1,
      "news": []
    }
  ]
}
```

- `intraday_path`는 5분봉 전체를 보관하되 차트에 필요 없는 OHLC 열은 넣지 않는다.
- 기존 `events`, `overnight_news`, `top_news`, `disclosures`는 호환성을 위해 유지한다.
- 과거 JSON처럼 새 필드가 없어도 기존 글 목록이 정상적으로 보여야 한다.
- 유효하지 않은 가격, 중복 시각, 장 시간 밖의 봉은 저장 전에 제거한다.

## 차트 설계

### 좌표

- Y좌표는 09:00~15:30을 선형 변환한다. 데이터가 14:55까지만 있으면 실제 마지막 수집 시각을 표시하고
  14:55~15:30 영역은 점선과 **「5분봉 미수집 구간」** 안내로 남긴다.
- X좌표는 당일 최저가~최고가에 좌우 여백 5%를 더해 변환한다.
- 고가와 저가가 같으면 축 폭을 최소 1호가 이상 확보해 0으로 나누지 않는다.
- 전일 종가와 시가는 차트 안에 얇은 세로 기준선으로 표시한다.

### 뉴스 배치

- 뉴스는 기사 발행 시각 기준이며 실제 정보가 시장에 알려진 시각과 다를 수 있음을 차트 바로 아래에 적는다.
- 전환점 기준 기존 창(전 90분~후 15분)을 그대로 사용한다.
- 여러 전환점에 같은 기사가 걸리면 차트에는 최초 한 번만 표시하고 목록에는 기존 기록을 유지한다.
- 모바일에서 제목이 차트를 밀어내지 않도록 제목은 두 줄까지 보이고, 전체 제목과 링크는 접기 영역에서 제공한다.
- 뉴스가 없는 전환점도 숨기지 않고 **「관련 뉴스 없음」**으로 표시한다.

### 반응형 화면

- 데스크톱: 가격 영역 약 60%, 뉴스 설명 영역 약 40%.
- 모바일(375px): SVG 가격선 아래에 시간순 뉴스 카드가 이어지는 대체 레이아웃을 사용한다.
- 색상만으로 상승·하락을 구분하지 않고 `▲`, `▼`, `●` 기호와 설명을 함께 쓴다.
- 차트에는 `role="img"`와 날짜·등락·주요 전환점을 설명하는 접근성 문구를 둔다.
