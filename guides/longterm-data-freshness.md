# 장기 전망 자료 갱신

매일 10:17 KST에 새 자료를 확인한다. 보고서 생성 성공과 자료 수집 성공은 구분한다.
월간 그래프는 완료된 월까지만 사용하므로 매일 날짜가 늘어나지는 않는다.

| 영역 | 최신 자료 연결 | 지연·실패 시 처리 |
| --- | --- | --- |
| 세계 경기·한국 수출 | FRED API의 키 공백 제거 → 동일 계열 공개 CSV | 실패하면 보관본, 기준월·조회 상태 표시 |
| 한국 선행지수·코스피 | OECD API + Yahoo 월말 종가 재조회 | 각 계열의 보관본·기준월 별도 표시 |
| 수출·환율과 주가 | 같은 실행의 수출 스냅샷 중 환산 검증된 관세청 월간 보완값 | KOSIS 원값 우선, 환산월·배율 표시 |
| 과거 검증 그래프 | 원본 통계와 월말 주가, 기존 발표 지연 유지 | 원본 기준월·출처와 모델 시간 정렬 설명 |

한국 총수출 `XTEXVA01KRM667S`는 **달러·계절조정 계열**이다.
관세청 미조정 총수출이나 반도체 수출을 여기에 이어 붙이지 않는다.
12개월 증가율은 결측월을 삭제하지 않은 달력에서 같은 달끼리 비교한다.

수출 스냅샷의 `monthly_info.customs`에 검증 상태·환산 배율·보완월을 기록한다.
이를 확인한 월간 값만 주가·환율 참고 그래프에 추가한다. 기존 KOSIS 값과 과거 모델 입력은 덮어쓰지 않는다.
10일·20일 잠정치의 월 전체 추정은 기존 최신 수출 시나리오에서만 표시한다.

관측월이 현재보다 2개월 넘게 뒤처지면 자료 지연 안내를 표시한다.
이는 자동 오류 판정이 아니라 출처의 발표 일정을 확인하라는 표시다.
조회에 성공해도 원천기관에 새 달이 없으면 기준월은 유지된다.

관련 구현: `tools/longterm_freshness.py`, `build_longterm_report.py`, `export_refresh.py`.
관련 테스트: `test_longterm_freshness.py`, `test_longterm_report.py`, `test_export_refresh.py`.
