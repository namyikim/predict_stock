# 가상 매매 파동 전략 개선 구현 계획

> 후속 작업자: `superpowers:executing-plans`를 사용해 아래 단계를 하나씩 구현한다. 각 단계의 검증·커밋·push·원격 확인을 마친 뒤 사용자에게 결과를 보고한다. 다음 단계와 묶어서 완료 처리하지 않는다.

**목표:** 현재 관찰용 가상계좌를 보존하면서 박스권 반등·상승 추세 눌림목 전략을 같은 기간과 위험 한도로 비교한다. 비용 차감 수익과 손실 위험의 개선 여부를 검증하며, 수익 극대화를 보장하지 않는다.

**구조:** 기존 예측 원장은 읽기 전용으로 유지한다. 시세 수집, 신호 계산, 체결·위험 관리, 기간 분리 평가, 실험실 표시를 분리한다. 새 전략은 별도 버전·별도 장부로 운영하고, 백테스트와 실제 시점 모의운용을 구분한다.

**기술:** 기존 Python·pandas·SQLite·unittest, 실험실 JavaScript·Node 테스트, GitHub Actions. 증권사 실주문 연결은 범위에서 제외한다.

**설계 근거:** [기존 자동매매 계획](automated-trading-plan.md), 2026-10-06 사용자 요청(단기 파동의 낮은 위치에서 진입해 높은 위치에서 청산하는 방법 검토, 계획을 먼저 push하고 단계별 진행).

## 현재 기준선과 범위

- `docs/lab/trading_sim.js`: 사전 방향 예측에 따른 시가 진입·종가 청산 및 보유 기준선.
- `tools/paper_trading.py`, `tools/run_paper_trading.py`: 상승확률 > 하락확률인 경우 하루 최초 진입 판단, 09:45 이후 판단·다음 실행의 신선한 완료 1분봉으로 모의 체결, 14:30 신규 진입 종료·15:00 이후 청산 시도.
- 현 설정: 초기 자금 1천만원, 종목별 30%·반도체 합산 50%, 수수료 편도 0.015%·매도세 0.18%·불리한 체결 차이 편도 0.05%. 실제 요율이 아닌 비교용 가정이다.
- 일일 손실 3%는 신규 매수 중지 조건이며 손실 상한 보장이나 즉시 강제청산 기능이 아니다.
- 검토 시 저장본: 2026-10-06 12:57 KST 관측, 시세 2건·주문/체결/결정 0건. 원인을 확정하지 않았으며 1단계에서 최신 상태를 다시 확인한다.
- 기존 분리 평가 자료는 두 종목 모두 평가 7거래일로 부족하다. 기존 성적을 새 전략의 성과로 재사용하지 않는다.
- 우선 일봉 기반 1~5거래일 실험을 구현한다. 장중 5분봉 실험은 전체 분봉과 신뢰할 수 있는 관측·실행 기반이 확보된 뒤 같은 엔진에 연결한다. 현재 15분 간격 예약으로 5분 단위 실시간 체결이 가능하다고 표시하지 않는다.

## 공통 제약

- `forecast_history/`와 기존 `paper_history/account.sqlite`를 초기화·덮어쓰지 않는다. 설정 변경으로 기존 계좌의 과거를 다시 계산하지 않는다.
- 미래 봉으로 확정된 저점·고점, 당일 최종 고저가, 발표 전 뉴스·수급을 당시 신호에 사용하지 않는다.
- 시세 시각·수집 시각·봉 종료 시각·결정 시각·주문 및 체결 시각을 구분한다. 결정 이전 가격으로 소급 체결하지 않는다.
- 전일 종가 대비 방향 예측을 진입 이후 기대수익으로 취급하지 않는다. 장중·다음 날·다일 보유의 목표 구간을 명시한다.
- 수수료·매도세·스프레드/체결 차이·미체결·지연·가격 갭을 평가에 포함한다. 현재 비용과 2배 비용을 함께 비교한다.
- 분할·배당·거래정지와 수정주가를 다룬다. 지표용 조정 계열과 현금 체결용 비조정 계열을 혼용하지 않는다. 기업행사 조정 불가 구간은 이유를 남기고 평가에서 제외한다.
- 당장 수익성이 좋아 보이는 전략으로 자동 전환하지 않는다. 새 전략 활성화는 검증 결과를 보고 별도 결정한다.
- 구현마다 기존 정책을 바꾸는 부분을 명시하고, 관련 테스트와 실제 확인 범위를 보고한다. 테스트 통과와 운영 수익성 입증을 구분한다.

## 중점 검토와 담당 단계

1. 시세 지연·휴장·결측·관측 실패: 이유를 기록하고 거래를 건너뛴다(1·2·5단계).
2. 같은 봉에서 목표가와 손절가를 모두 통과: 체결 순서를 유리하게 가정하지 않는다(4단계).
3. 급락 갭·장 마감 실행 누락: 지정 손절가 체결이나 당일 청산 성공을 보장하지 않는다(4·5단계).
4. 반복 실행·설정 변경·저장 충돌: 중복 주문과 장부 덮어쓰기를 막는다(5단계).
5. 분할·배당·시간대 경계: 인위적인 파동과 가짜 수익을 만들지 않는다(2·4·6단계).

## P3. 파동 신호를 순수 함수로 구현

**파일:** 신규 `tools/wave_signals.py`, `macro_inputs/wave_strategies.json`, `tests/test_wave_signals.py`.

**인터페이스:** `wave_signal(bars, *, decision_at, config) -> dict`. P2 입력에서 사용 가능한 봉만 받아 `action`(enter/wait), `regime`, `range_position`, `reason_codes`, `information_cutoff`, `reference_stop`을 반환한다. 주문·체결·실제 결과는 읽거나 쓰지 않는다.

**동결할 최초 연구 후보:** 이전 완료 20개 봉의 고저 범위와 완료 봉만으로 계산한 20봉·60봉 이동평균 및 20봉 평균의 5봉 전 대비 변화로 큰 방향을 판정한다. 범위가 0이거나 자료가 부족하면 관망한다. 임계값은 검증용 시작값이며 최적값이 아니다.

- 박스권 반등: 20봉 평균의 5봉 전 대비 변화 절댓값이 1% 이하, 직전 완료 봉 종가가 그 이전 20봉 범위 하단 20% 이내, 최신 완료 봉 종가가 직전 봉 고가를 회복했을 때 후보 진입.
- 상승 눌림목: 20봉 평균이 5봉 전보다 높고 60봉 평균 위, 직전 종가가 20봉 평균 이하로 조정된 뒤 최신 종가가 20봉 평균과 직전 고가를 모두 회복했을 때 후보 진입.
- ‘예측 결합’은 별도 후보로 둔다. 동일한 정보 마감·보유 구간의 예측이 없으면 결합 후보는 거래하지 않는다. 가격 단독 후보와 결과를 섞지 않는다.
