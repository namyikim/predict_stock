# 장기 전망의 기준금리·물가 비교

삼성전자·SK하이닉스의 **장기 전망 → 장기 전망 (월간)** 상단에 한국 기준금리와
소비자물가 상승률을 같은 % 눈금으로 표시한다(2026-10-19 요청).

- 기준금리: 한국은행 ECOS `722Y001/0101000` 일별 관측치의 월평균. 국채 금리나 현재 결정금리와 구별한다.
- 소비자물가: ECOS `901Y009/0` 총지수를 12개월 전 같은 달과 비교한 상승률.
- 최근 10년을 표시한다. 진행 중인 달은 제외하며, 결측월은 채우지 않는다.
- 최신 공통월의 두 수치와 차이(%p), 지표별 최신 관측월을 함께 표시한다.
- 실질금리 참고값(기준금리−최근 물가 상승률)을 보라색 일점쇄선으로 겹친다.
  0% 기준선 위는 연녹색, 아래는 연분홍색이며 최신 값의 양수(+)·음수(−)·0 수준을 표시한다.
  같은 달에 두 지표가 모두 있는 경우만 계산한다. 기대물가 대신 최근 물가를 쓴 근사값이다.
- 가로축은 발표일이 아닌 관측월이다. 이 자료는 경제환경 설명용이며 예측·백테스트 입력으로 넣지 않는다.

기존 일일 장기 전망 워크플로가 `ECOS_API_KEY`로 조회한다. 성공 자료는
`macro_history/policy_inflation.csv`에 누적하며 부분 조회 실패 시 기존 값을 보존한다.
보관본 사용·2개월 초과 지연·자료 없음은 화면에 명시한다. API 키·예외 원문은 결과에 기록하지 않는다.

구현: `tools/policy_inflation.py`, 연결: `tools/build_longterm_report.py`.
검증: `python -m unittest discover -s tests -p 'test_policy_inflation.py'`.
