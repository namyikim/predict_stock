# 보고서 탭 구성

오늘의 예측에는 쉬운 요약, 현재 시장 정보, 다음 거래일 방향, 수급, 시초가·종가 예상만 둔다. 요약 안의 과거 성적 카드는 예측 성적 탭으로 이동하고 연결 링크를 남긴다.

예측 성적 탭 순서:
1. 실제 발행 후 누적 성적
2. 최근 예측 vs 실제(최근 20·60일, 이벤트일, 아침·저녁 비교 포함)
3. 지난 거래일/오늘 장 회고
4. 모델의 과거 검증 성적
5. 예측 해석의 상세 수치(AUC·거래비용 등)
6. 학습·검증 설정(접힘)

각 탭의 h3는 1부터, h4는 상위번호.1부터 번호를 붙인다. 제목의 날짜·부제·기존 링크 ID는 보존한다. 부분 갱신 후에도 브라우저에서 번호를 다시 정리한다.

생성 경로는 `report_html.tabify_sections`, 발행된 페이지 이행은 `report_html.refresh_layout`이다. `SCORECARD`, `LEDGER_SECTION`, `REVIEW_SECTION` 경계는 각각 같은 탭 안에 보존해 오후 채점·복기 갱신을 유지한다. 모델·예측값·채점 계산은 변경하지 않는다.

검증: `python -m unittest discover -s tests -p 'test_report*.py'`.
