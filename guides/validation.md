# 모델 검증과 결과 판정

## 가장 중요한 원칙

좋아 보이는 백테스트 숫자보다 **미래 정보를 차단한 검증**, **단순 기준선과의 차이**, **실제로 미리 기록한 예측 성적**을 우선합니다. 성능 차이의 신뢰구간이 0을 포함하면 우위라고 말하지 않습니다.

## 타깃과 예측 구간

기본 방향 타깃은 전일 종가 대비 다음 거래일 종가입니다. 하락·보합·상승 세 클래스로 나누며 보합 범위는 과거 변동성만으로 계산합니다.

종가→종가를 다음 두 구간으로 분해해 평가합니다.

- 갭: 전일 종가 → 다음 거래일 시가
- 세션: 당일 시가 → 당일 종가

과거 검증에서는 성능 대부분이 갭에서 나타났고 세션은 대체로 무작위에 가까웠습니다. 따라서 전체 방향 정확도만으로 거래 가능성을 판단하지 않고 `auc_session`과 거래비용 차감 후 손익을 별도로 봅니다.

## 시간순 검증

무작위 셔플을 사용하지 않습니다. 각 워크포워드 폴드는 과거 구간으로 학습하고 그보다 뒤의 구간에서 평가합니다.

- 학습·검증·외부 평가 기간을 시간순으로 분리
- 모델 선택과 확률 보정을 외부 평가 라벨과 분리
- 겹치는 5·20거래일 타깃은 지평만큼 purge
- 모델과 기준선을 같은 날짜에서 쌍체 비교
- 월 단위 자기상관을 고려한 월 블록 부트스트랩 95% 신뢰구간

## 데이터 누수 방지

- 국내 특징은 예측일 이전까지 확정된 값만 사용합니다.
- 해외 자산은 한국 아침 예측 시각 전에 마감된 봉만 연결합니다.
- 보합 밴드는 당일 수익률이 아니라 이전까지의 변동성으로 계산합니다.
- 월별 통계는 발표 시각 또는 보수적인 지연 규칙 뒤에만 공개합니다.
- 뉴스심리는 지수 날짜+14일 뒤에 연결합니다.
- 수급은 장 마감 뒤 확정되므로 다음 거래일부터 사용합니다.
- 보조 시계열에 구멍이 있으면 며칠 수익률을 1일 수익률로 바꾸지 않고 결측으로 둡니다.

합성 데이터 테스트는 당일 가격을 크게 바꿔도 같은 날 특징과 밴드가 변하지 않는지 직접 확인합니다.

## 비교 모델과 기준선

방향 모델은 Logistic과 LightGBM의 확률을 단순 평균합니다. 다음 기준선·제외 모델을 함께 기록합니다.

- 항상 보합 또는 클래스 사전확률
- 이전 고정 설정 앙상블
- 월별 지표 제외
- 뉴스심리 제외
- 외국인·기관 수급 제외
- 유가·엔화 등 거시 가격 제외

가격 모델은 `현재 가격 유지`를 기준선으로 사용합니다. 영업이익 모델은 직전 분기와 4분기 전 영업이익을 기준선으로 사용합니다.

## 주요 지표

| 지표 | 읽는 법 |
| --- | --- |
| `balanced_accuracy` | 클래스 불균형을 보정한 방향 적중률 |
| `log_loss` | 확률 품질; 작을수록 좋음 |
| `brier` | 확률 오차; 작을수록 좋음 |
| `auc_gap` | 야간 갭 방향 판별력 |
| `auc_session` | 실제 장중 구간 방향 판별력 |
| `session_bp_net` | 거래비용 차감 후 장중 평균 손익 |
| `MAE` | 가격·영업이익 평균절대오차 |

차이의 95% 신뢰구간이 0을 포함하면 `동률`로 읽습니다. 하나의 지표를 높이기 위해 밴드나 설정을 외부 평가 구간에 맞춰 다시 고르지 않습니다.

## 자동 판정

보고서는 다음 질문을 코드로 평가합니다.

1. 세션 AUC가 0.5보다 의미 있게 큰가?
2. 거래비용 차감 후 기대손익 하한이 0보다 큰가?
3. 방향 성능이 단순 기준선보다 유의하게 나은가?
4. 확률 품질이 클래스 사전확률보다 나은가?
5. 나쁜 폴드가 절반 미만인가?
6. 시초가예측이 `갭 0%` 기준선을 이기는가?
7. 중기 가격 예측이 `현재가 유지` 기준선을 이기는가?
8. 라이브 특징이 오래된 값으로 대체되지 않았는가?
9. 학습 데이터가 최신인가?

검증에 실패하면 점 예측을 숨기거나 `거래 가능한 예측력이 확인되지 않습니다`라고 표시합니다.

## 실제 사전 예측 원장

백테스트는 모델 개발에 사용되므로 낙관적일 수 있습니다. 공식 평가는 `forecast_history/`에 처음 기록한 사전 예측만 사용합니다. 같은 날짜·모델·설정의 후속 실행은 기존 예측을 바꾸지 않습니다.

원장은 실제 시가·종가가 나온 뒤 채점되며 최근 20·60거래일 창을 보고합니다. 하루 결과로 설정을 자동 변경하지 않습니다.

## 방법론 스위치

주요 선택은 설정으로 되돌릴 수 있고 이전 방법도 비교 행으로 남깁니다.

| 설정 | 현재 선택 | 비교 목적 |
| --- | --- | --- |
| `SELECTION_METRIC` | `log_loss` | 확률 모델을 proper scoring rule로 선택 |
| `HEADLINE_MODEL` | `No macro ensemble` | 시세만 모델을 대표로 두고 전체 특징 효과를 별도 측정 |

월별 지표·뉴스심리·수급이 시세만 모델보다 낫다는 사전 예측 근거가 쌓이면 원장 비교를 바탕으로 변경합니다.

## Transformer 실험

Transformer는 기본 앙상블에 자동 편입하지 않습니다. `RUN_TRANSFORMER=True`로 같은 폴드에서 실행하고 다음을 비교합니다.

- Transformer 단독
- Logistic+LightGBM 단순 평균
- 단순 평균+Transformer

쌍체 log loss 차이의 신뢰구간이 0을 벗어날 때만 편입 여부를 검토합니다. 실험 결과는 `experiments/transformer/`에 별도 기록하며 공식 원장을 바꾸지 않습니다.

## 장기·영업이익 검증

3·6·12개월 장기 전망은 겹치는 타깃을 제거한 독립 표본이 20개 미만이면 우위를 판정하지 않습니다. 기준선을 이기지 못하면 점 예측 대신 국면별 분포와 유사 시기만 보여 줍니다.

분기 영업이익은 진행 중인 분기의 앞 k개월 자료만 사용하고 과거 분기도 같은 k개월로 학습합니다. 워크포워드 MAE가 직전 분기와 4분기 전 기준선을 모두 이길 때만 숫자를 냅니다.
