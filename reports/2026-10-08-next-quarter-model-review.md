# 4분기 선행 전망 수정 — 2026-10-08

## 문제와 변경

기존 다음 분기 모델은 분기 t의 실적이 아직 없다고 가정해 t-1 실적만 사용했다.
3분기 실적이 발표된 뒤에도 4분기 전망에 2분기 이익만 들어가고, 잠정 실적은
모델 계산 이후 조회되어 채점에만 사용되는 문제가 있었다.

발표 사실이 확정 실적·잠정 공시·이미 채점된 원장 중 하나로 확인되면, 수출 3개월
전체 자료 조건에서 발표 후 전용 전망을 사용한다. 발표 전 또는 부분월이면 기존 경로를 유지한다.
새 경로는 기존 회귀, 발표 실적을 특징으로 쓰는 회귀, 발표 실적 대비 다음 분기 변화량을
학습하는 회귀를 비교한다. 후보들은 동일한 과거 분기를 사용하고 앞 절반 MAE로만 선택한다.
뒤 절반에서는 마지막 발표 실적 유지·전년 동기 유지 기준선 모두를 이겨야 숫자를 공개한다.

현재 발표 실적은 다음 분기 실시간 학습과 기준값에는 반영하지만 모델 선택·평가에서는
해당 실적을 제외한다. 다음 분기 실제값과 미래 행은 학습·선택에 사용하지 않는다.
원장에 이미 있는 4분기 최초 예측은 그대로 보존한다. 아래 값은 최신 전망이다.

## 고정 입력 재계산

입력 커밋: `acee1d4ea76b032854fe6a2c58eb9295f758f9ca`.
파일별 SHA-256과 전체 결과: `experiments/earnings_next_20261008/evaluation.json`.

- 삼성전자: 발표 실적 107.4조 원 반영. 기존 CLI 제외 원시 추정 160.65조 → 새 공개 추정 **135.57조 원**.
- 선택된 모델: 발표 실적 대비 변화 보정. 평가 구간 MAE 13.90조 → 6.75조(약 51.5% 감소).
- 평가 11개 분기의 예측 대상은 2023Q4~2026Q2. JSON의 first/last는 수출 입력 분기(한 분기 전).
- 발표 실적 반영 일반 회귀의 평가 MAE는 6.51조로 더 작았지만, 앞 절반 선택 구간에서
  변화 보정이 더 좋았으므로 평가 결과를 보고 선택을 바꾸지 않았다.
- 하이닉스는 3분기 발표 실적이 입력에 없어 현재 전망에 새 경로를 적용하지 않는다.
  마지막 확정 분기를 기준으로 발표 후 조건의 과거 비교 결과도 JSON에 기록했다.

```bash
python tools/evaluate_earnings_next.py --source-ref acee1d4ea76b032854fe6a2c58eb9295f758f9ca --out experiments/earnings_next_20261008
python -m unittest tests.test_earnings_next_release tests.test_earnings_anchor tests.test_earnings_forecast -q
```

관련 112개 검사 통과. 전체 프로젝트 검사·라이브 API·배포 화면 확인은 로컬에서 수행하지 않았다.
보고서에는 발표 실적, 선택한 방식, 후보별 같은 기간 성적을 표시한다.

## 해석의 한계

과거 확정·수정 자료 기준의 사후 연구다. 당시 잠정 실적 빈티지를 재현한 검증이 아니며,
후보 설계 자체가 이번 실패 이후 이뤄졌으므로 미래 성적 개선을 보장하지 않는다.
4분기 수출은 아직 반영하지 않은 선행 전망이며, 3분기 수정치 110.35조를 다시 입력하거나
107.4조에 임의의 증가율을 곱한 결과가 아니다. 발표된 실제 실적에서 과거 관계로 변화를 추정한다.
